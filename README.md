# SPS Group – Frontend

Interface React para gerenciamento de usuários.

## Requisitos

- Node.js v18+
- API do backend rodando em `http://localhost:3000`

## Instalação

```bash
npm install
```

## Executando

```bash
npm start
```

Acesse `http://localhost:3001` no navegador.
